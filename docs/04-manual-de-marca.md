# MANUAL DE MARCA
## Sistema de identidad visual y verbal de Clientum
### Versión 1.0 - Septiembre 2026

## 01. Esencia de marca
Clientum es el sistema operativo comercial que permite a las PyMEs centralizar operaciones, automatizar flujos de trabajo, mejorar la comunicación y optimizar el crecimiento.

*   **Propósito:** Tecnología simple que permite a las PyMEs escalar sus negocios con control y profesionalismo.
*   **Personalidad:** Profesional, Cercano, Tecnológico, Resolutivo.
*   **Promesa de marca:** Confianza.

## 02. Sistema de logotipo
*   **Versiones autorizadas:** Logotipo horizontal, Isotipo.
*   **Área de protección:** Debe mantenerse libre para asegurar la visibilidad.
*   **Tamaño mínimo:** 209 pixels horizontal.

## 03. Paleta cromática
*   **Navy (Primario):** #022046 (Fondo institucional)
*   **Blue (Corporativo):** #002B5C (Acción, enlaces)
*   **Action (Acción):** #0056B3 (Éxito, confirmación)
*   **Success (Éxito):** #4CAF50
*   **Surface:** #F5F7FA
*   **Ink (Texto principal):** #212121

## 04. Tipografía
*   **Primaria:** Inter.
*   **Alternativa:** Arial.

| Uso | Fuente/Peso |
| :--- | :--- |
| H1 | Bold/700 |
| H2 | SemiBold/600 |
| H3 | Medium/500 |
| Cuerpo | Regular/400 |
| CTA | SemiBold/600 |

## 05. Lenguaje visual
*   **Recursos gráficos:** White cards en light grey, bordes redondeados (12-16px), soft shadows.
*   **Fotografía:** Fotos reales de PyMEs, evitar stock artificial.

## 06. Identidad verbal
*   **Tono:** Profesional, claro, directo.
*   **Palabras preferidas:** Simple, claro, automatizar.
*   **Evitar:** Magia, garantizado.

## 08. Usos incorrectos
*   No estirar el logotipo.
*   No cambiar colores.
*   No añadir efectos o sombras pesadas.
