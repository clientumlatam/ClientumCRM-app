# 08 · Roadmap y Guías de Mantenimiento

## 1. Ciclo de Vida y Auditoría de Código
- **Validaciones Periódicas**: Ejecutar `npm run lint` para comprobar tipado estricto con TypeScript (`tsc --noEmit`).
- **Verificación de Compilación**: Ejecutar `compile_applet` tras cambios estructurales importantes.
- **Control de Versiones y Marca**: Cualquier ajuste en paleta de colores, tipografía o identidad visual debe alinearse con el *Manual de Marca de Clientum (Versión 1.0)*.

## 2. Roadmap Tecnológico
- **Q3 2026**: Consolidación de integraciones AFIP WSFE y pasarelas de pago regionales.
- **Q4 2026**: Ampliación de agentes autónomos con IA para recordatorios automáticos de cobranza y sincronización contable avanzada.
- **Q1 2027**: Versión nativa complementaria para dispositivos móviles.
