# 08 · Roadmap y Guías de Mantenimiento

## 1. Ciclo de Vida y Auditoría de Código
- **Validaciones Periódicas**: Ejecutar `npm run lint` para comprobar tipado estricto con TypeScript (`tsc --noEmit`).
- **Verificación de Compilación**: Ejecutar `compile_applet` tras cambios estructurales importantes.
- **Control de Versiones y Marca**: Cualquier ajuste en paleta de colores, tipografía o identidad visual debe alinearse con el *Manual de Marca de Clientum (Versión 1.0)*.

## 2. Roadmap Tecnológico
- **Q3 2026 (Completado/En curso)**: 
    - ✅ Implementación de **Modo Enfocado (Focus Mode)** para usuarios ejecutivos.
    - ✅ Estructura base de **Facturación AFIP** (WSFE / WSAA).
    - 🔄 Consolidación de integraciones AFIP (Factura A, B, C y Notas de Crédito).
    - 🔄 Pasarela de pagos regionales (Mercado Pago).
- **Q4 2026**: 
    - Ampliación de agentes autónomos con IA para recordatorios automáticos de cobranza.
    - Sincronización contable avanzada con sistemas ERP locales.
    - Integración de WhatsApp Multiagente (Baileys / Cloud API).
    - **Dashboard de Auditoría Avanzada**: Visualización gráfica de anomalías de seguridad.
- **Q1 2027**: 
    - Versión nativa complementaria para dispositivos móviles (PWA Avanzada / Capacitor).
    - Módulo de Inteligencia de Negocios (BI) con modelos predictivos de Churn y LTV.
    - **Clientum Marketplace**: Sistema de plugins para extensiones de terceros.
